### What init did that the plan did not expect

`init` printed an "Updating fonts" step and rewrote `app/layout.tsx`. It replaced the Bricolage Grotesque loader with `Geist({subsets:['latin'],variable:'--font-sans'})`, added `import { cn } from "@/lib/utils"`, and changed the `<html>` class to `cn("h-full", "antialiased", "font-sans", geist.variable)`. Committed as generated, the page would render in Geist. That fails this issue's own check (the `h1` still computes to Bricolage Grotesque) and the plan's one-family decision in section 4, and it would undo issue #4 from Phase 1.

The file was restored with `git checkout -- app/layout.tsx`. The issue body says "commit what it generates as-is"; that sentence was written before anyone knew `init` touched the layout, and the issue closes with this pull request, so it stays as written. The plan's facts now say what `init` does to the layout and what to do about it.

`npx shadcn@latest init --help` lists no flag that skips the font step. `--yes` defaults to true, so the command ran without a prompt.
