- `SiteHeader` and the layout (#26): same branch, next commit.
- Closing the sheet when the viewport crosses `md` while it is open. Needs a `matchMedia` listener in an effect. Cost: about eight lines; the close button, Escape and the backdrop already cover the case, and a phone does not grow past 768px on its own.
- `aria-current` or a highlighted link for the section in view: not in the plan; the same scroll-spy cost as in #24.
- A `SheetDescription`. Base UI sets no `aria-describedby` without one, and a menu needs no description. Cost: one element and a sentence nobody needs.
- `modal="trap-focus"` or `modal={false}` to let the page scroll behind the sheet. The default locks scroll and hides the page from assistive tech, which is what a navigation drawer wants. Cost: one prop, for a worse experience.
- A reduced-motion variant of the 200ms slide and fade. Those classes live in the generated `components/ui/sheet.tsx`, which the plan leaves as generated, and section 4 allows the sheet to animate because the visitor triggers it. Cost: a `motion-reduce:` class in a generated file, or a global rule in Phase 7.
