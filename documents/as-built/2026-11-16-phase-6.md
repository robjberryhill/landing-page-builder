### The choices

Two were decided by Rob on 2026-11-16 before the work started and are in the issue. The rest the issue left open.

| Choice | Used | Why |
|---|---|---|
| Where the heading sits | Centred: `align="center"` on `SectionHeading`. Rob's decision. | Left-aligned, the heading sat at the container's left edge and the accordion 160px to its right. Centred, the 672px heading block has 208px on each side at 1280px and the 768px accordion has 160px on each side, so both share the page's centre line. |
| Text sizes | 16px for questions and answers: `text-base` on `AccordionTrigger` and on `AccordionContent`. Rob's decision. | The generated parts are 14px. The generated panel itself still computes 14px, because `AccordionContent` puts `className` on an inner `<div>` and not on the panel; the inner `<div>` and the answer paragraph compute 16px, measured, so the answer the visitor reads is 16px. |
| Row padding | 16px above and below each question (`py-4`), 16px under each answer (`pb-4`) | The generated 10px gave a 46px row. With 16px text that was tight, and under the 48px the hero's and tiers' controls are near. Rows are now 58px. |
| Dividers | The generated `not-last:border-b`, unchanged | It computes to 1px `rgb(230, 222, 210)`, the `line` colour section 4 expects, on the first five items and 0px on the last. |
| `"use client"` | None in `faq.tsx` | Base UI's accordion modules carry the directive themselves, and the generated `components/ui/accordion.tsx` imports them. `npm run build` lists `/` as static with the section on the page. |
| Find in page | `hiddenUntilFound` on `Accordion` | Without it a closed answer is not in the page at all: the first run showed no panel element for five of the six items. With it, closed panels stay in the page with `hidden="until-found"`, and the browser opens the one a search lands in. Measured by loading `/#:~:text=Swiss%20Water`: the page scrolled to the FAQ and "Do you have decaf?" was the open item. All six answers are also in the prerendered HTML as elements, which they were not as rendered elements before. |
| Reduced motion | A class on the wrapper, `motion-reduce:**:data-[slot=accordion-content]:animate-none!`, held in a `noMotion` constant | The first run showed the panel animating for 0.2 seconds with `prefers-reduced-motion: reduce` emulated, the same as without it. The site already turns smooth scrolling off for those visitors. The generated panel takes no class of its own, so the switch is set from the wrapper and reaches the panel as a descendant; `components/ui/accordion.tsx` and `app/globals.css` stay untouched. |
| Blank items | An item with a blank question or a blank answer is left out (`hasText` from `lib/text.ts`) | The other sections get this from their blocks. This section composes the generated parts directly, so it guards its own array. A blank question would be a button with no name. |

### Review pass

**1. Error and empty states.** The section fetches nothing. Its states come from the `faqs` array, a literal in the same file, and from the accordion.

- All six closed, which a visitor reaches by clicking the open question: six questions and no answer. Any click opens one. Nothing is stuck.
- A blank question: the sketch rendered a button with no text, which a screen reader announces as an unnamed button inside an empty heading. **Fixed**: the item is left out.
- A blank answer: the sketch rendered a question that opens onto nothing. **Fixed**: the item is left out.
- An empty array, or every item blank: the heading renders above an empty accordion. **Not fixed**, as in the other four sections; the array is a literal a few lines above the JSX. Cost in item 5.
- Two items with the same `value`: both open and close together, and React logs a duplicate key warning in development. The JSDoc tells the editor to give a new item its own `value`.
- The item named in `defaultValue` removed or renamed: nothing is open on load. Any click opens one.
- Find in page for a word inside a closed answer: without `hiddenUntilFound` the browser reports no match for text that is on the site, and the visitor concludes the answer is not there. **Fixed**, measured above.
- A visitor who asks for reduced motion: the panel animated anyway. **Fixed**, measured above.
- The answer to "Can I pause or cancel?" says "from your account page". The site has no account page. The copy is the plan's and the site is a fictional brand; see item 5.

**2. Type fields rendered by the UI.** Each `faqs` object has three fields. `question` renders as the button's text. `answer` renders as the paragraph in the panel. `value` renders no text: it is the item's identity for the accordion, the React key, and what `defaultValue` names. `SectionHeading` gets `align`, `title` and `description`. `Accordion` gets `defaultValue` and `hiddenUntilFound`.

**3. Permission gates per route.** Not applicable. One static route, `/`, with no service calls and no auth. The build still lists it as static, with a client component now inside the page.
